# Phishing Email Detection & Awareness System

## Task 2 - Future Interns Cyber Security Internship

### Objective

The objective of this project is to analyze different types of emails, identify phishing indicators, classify emails based on risk level, and create awareness about phishing attacks and email security.

### Tools Used

* Gmail
* Microsoft Word
* Canva
* GitHub

### Email Analysis

#### 1. Safe Email

* Sender: [reminder@email.airtelpaymentsbank.co.in](mailto:reminder@email.airtelpaymentsbank.co.in)
* Classification: Safe
* Indicators:

  * Official-looking sender domain
  * Professional formatting
  * No request for passwords or OTPs
  * Legitimate banking communication

#### 2. Suspicious Email

* Sender: [updates@simplilearnmailer.com](mailto:updates@simplilearnmailer.com)
* Classification: Suspicious
* Indicators:

  * Marked as spam by Gmail
  * Urgent subject line
  * Password update request
  * Requires sender verification

#### 3. Phishing Email

* Sender: [support@hdfc-security-update.com](mailto:support@hdfc-security-update.com)
* Classification: Phishing
* Indicators:

  * Fake sender domain
  * Urgent language
  * Suspicious link
  * Attempts to create fear and pressure

### Risk Classification

| Email Type       | Risk Level  |
| ---------------- | ----------- |
| Safe Email       | Low Risk    |
| Suspicious Email | Medium Risk |
| Phishing Email   | High Risk   |

### Awareness & Prevention Tips

1. Verify the sender's email address.
2. Avoid clicking suspicious links.
3. Never share passwords or OTPs through email.
4. Check for spelling and grammar mistakes.
5. Enable Multi-Factor Authentication (MFA).
6. Report suspicious emails to the organization.

### Outcome

This project successfully analyzed Safe, Suspicious, and Phishing emails. The findings help users understand common phishing techniques and improve cybersecurity awareness.
